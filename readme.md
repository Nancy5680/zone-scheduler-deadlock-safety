# Zone Job Scheduler, Deadlock Safety Engine and Smart City IoT Deployment Blueprint

## Overview

This project presents a zone-based job scheduling system designed to manage jobs efficiently while preventing deadlocks and unsafe resource allocation.

The project combines job scheduling, deadlock safety analysis, resource management, and a Smart City IoT deployment blueprint.

## Key Features

- Zone-based job scheduling
- Deadlock detection and prevention
- Safe resource allocation
- Job and resource management
- Smart City IoT deployment concept

## Objective

The main objective of this project is to design a reliable scheduling system that can allocate resources safely between different jobs and zones while avoiding deadlock situations.

## Technologies

- Python
- Algorithms and Data Structures
- Deadlock Detection and Avoidance
- Resource Allocation
- Smart City IoT Concepts
